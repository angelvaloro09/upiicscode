## Diseño modular

Las funciones en C permiten descomponer un algoritmo complejo en unidades lógicas independientes, reutilizables y comprobables.

### Paso por valor vs referencia simulada

En C, todos los argumentos se pasan por valor: la función recibe una copia exacta de los datos proporcionados por quien la llama. Para modificar una variable del ámbito exterior, es necesario pasar su dirección de memoria.

```c
#include <stdio.h>

void intercambiar(int *a, int *b) {
    int temporal = *a;
    *a = *b;
    *b = temporal;
}

int main(void) {
    int x = 15;
    int y = 30;

    printf("Antes del intercambio: x = %d, y = %d\n", x, y);
    intercambiar(&x, &y);
    printf("Después del intercambio: x = %d, y = %d\n", x, y);

    return 0;
}
```

<Callout type="ejemplo" title="Paso por referencia simulada">
  Al pasar `&x` y `&y`, la función `intercambiar` recibe copias de las
  direcciones de memoria de las variables originales, permitiendo alterar su
  contenido indirectamente mediante desreferencia.
</Callout>
