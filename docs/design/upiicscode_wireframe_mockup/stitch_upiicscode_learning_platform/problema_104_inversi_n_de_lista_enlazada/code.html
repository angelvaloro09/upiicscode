Inversión de Lista Enlazada

Algoritmos sobre memoria dinámica y redirección de punteros en un solo recorrido.

Descripción del problema

Dado el puntero inicial head de una lista simplemente ligada implementada en C/C++, invierte los enlaces de los nodos de manera iterativa o recursiva y devuelve la nueva cabeza de la lista invertida.

No debes modificar los valores internos de los nodos; únicamente está permitido reasignar los punteros de enlace (next).

Esquema en memoria (Estado Inicial vs. Estado Final) O(1) memoria auxiliar

Casos de Ejemplo

Formato estándar STDIN / STDOUT
Ejemplo 1
Entrada (STDIN) 
head = [1, 2, 3, 4, 5]
Salida Esperada 
[5, 4, 3, 2, 1]
Ejemplo 2 (Lista Pequeña)
Entrada (STDIN) 
head = [1, 2]
Salida Esperada 
[2, 1]

Restricciones Académicas

  • El número de nodos en la lista está en el rango 1 ≤ n ≤ 10^5.
  • El valor de cada nodo satisface -5000 ≤ Node.val ≤ 5000.
  • Complejidad temporal objetivo: O(n) en un solo pase.
  • Complejidad espacial auxiliar: O(1) de memoria adicional.
