3.1.1 Naturaleza de un Apuntador

En lenguaje C, la memoria principal es concebida como un vector unidimensional de bytes consecutivamente enumerados. Cada variable declarada en tiempo de ejecución reside en una ubicación fija determinada por el compilador y el sistema operativo.

Definición Formal

Un apuntador es una variable cuyo valor escalar no representa un dato de dominio (entero, carácter o flotante), sino una dirección hexadecimal que ubica el inicio de otro bloque de memoria.

3.1.3 Operadores & y *

El operador ampersand (&) extrae la dirección de una variable, mientras que el asterisco (*) actúa como operador de indirección o desreferenciación.

memoria.c 
#include <stdio.h>

int main(void) {
    int valor = 120;
    int *p = &valor;

    // Acceso directo y por indirección
    printf("Dato: %d\n", *p);
    *p = 250; // Modificación en destino

    return 0;
}
Paso por Referencia

C no soporta paso por referencia intrínseco. Toda invocación es por valor; sin embargo, al pasar la copia de un apuntador, la función receptora altera directamente la región de memoria original.

3.1.4 Memoria No Válida

Intentar acceder a una celda de memoria que no ha sido asignada a la pila o al montículo del proceso desencadena una interrupción de protección a nivel de MMU (Memory Management Unit).

warning
Excepción: Segmentation Fault (SIGSEGV)

Desreferenciar un apuntador no inicializado (int *ptr; *ptr = 5;) o un apuntador NULL causa la terminación inmediata del proceso por violación de segmento de memoria protegida por el kernel.
