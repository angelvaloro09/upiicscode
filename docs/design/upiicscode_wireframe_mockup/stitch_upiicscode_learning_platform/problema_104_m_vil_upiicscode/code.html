PROBLEMA #104 Memoria Dinámica

Inversión de Lista Enlazada

Reconfiguración secuencial in-situ de apuntadores de enlace simple sin asignación auxiliar de memoria.

Complejidad Temporal O(n) Estricta
Espacio Adicional O(1) in-situ

Descripción Formal

Dada la cabeza de una lista enlazada simple representada por la estructura ListNode* head, invierta el sentido de todos los punteros next de modo que el último nodo sea la nueva cabeza.

No está permitido transferir los valores a estructuras intermedias (arreglos, vectores o pilas STL). La mutación debe ocurrir puramente por reasignación de direcciones en memoria dinámica.

Mapeo de Punteros en Memoria Estado de Transición 
[Estado Inicial]
  head ──► [ 1 | ● ] ──► [ 2 | ● ] ──► [ 3 | NULL ]

[Iteración k: prev=1, curr=2, next=3]
  NULL ◄── [ 1 | ● ] ◄── [ 2 | ● ]     [ 3 | NULL ]
            ▲             ▲             ▲
            prev          curr          next_node

[Estado Final Requerido]
  head ──► [ 3 | ● ] ──► [ 2 | ● ] ──► [ 1 | NULL ]
Invariante: Al inicio de cada ciclo, la sublista predecesora a curr se encuentra ya invertida y anclada a prev.

// Estructura declarada en cabecera global ListNode* reverseList(ListNode* head) { ListNode* prev = nullptr; ListNode* curr = head; while (curr != nullptr) { ListNode* next_node = curr->next; curr->next = prev; prev = curr; curr = next_node; } return prev; }
