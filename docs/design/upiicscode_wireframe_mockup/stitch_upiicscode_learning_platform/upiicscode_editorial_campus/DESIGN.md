## Brand & Style

This design system establishes an academic, contemplative, and distraction-free digital workshop for computer science and informatics students at UPIICSA IPN. It replaces the anxiety of gamified coding platforms, competitive dashboards, and sensory overload with the quiet clarity of an open notebook, the structural serenity of Google Classroom, and the typography-first reading comfort of Apple Books.

### Core Principles
- **Clarity Over Velocity:** Code comprehension takes precedence over speed metrics. Interface chrome recedes completely to spotlight problem statements, algorithmic structures, and compiler feedback.
- **Academic Serenity:** The workspace feels like a well-lit campus library at morning. No streaks, no floating badges, no loud saturation, and no neon gradients.
- **Institutional Dignity:** The iconic Guinda IPN is treated as a precise mark of intent—an understated visual anchor rather than an aggressive wash.
- **Pedagogical Warmth:** Communication adopts an authentic, respectful Mexican Spanish with a warm, encouraging pedagogical tuteo (*"Revisa tu caso base"*, *"Tu solución compiló correctamente"*).

### Visual Movement
Minimalist Academic Editorial: Flat, light-catching surfaces, bone-toned backgrounds, hair-thin structural divisions, generous whitespace margins, and high-readability monospace typography for code artifacts.

## Colors

The palette balances institutional identity with prolonged ocular stamina for late-night problem-solving.

### Foundation & Neutrals
- **Canvas Base (Light):** `#FBFBFA` (Bone / Warm Alabaster) provides an organic, non-glare foundation.
- **Surface Elevation (Light):** `#FFFFFF` (Pure White) strictly reserved for interactive cards, reading panes, and code blocks.
- **Subtle Surface (Light):** `#F3F2EE` for secondary sidebars, problem meta shelves, and table headers.
- **Border Subtle:** `#E7E6E2` for 1px hairline segmentations.
- **Carbon Ink (Primary Text):** `#1E1E20` offering deep contrast without harsh pure black.
- **Carbon Muted (Secondary Text):** `#4A4A4F` for supporting descriptions, subheadings, and problem constraints.
- **Carbon Subtle (Tertiary / Placeholders):** `#76767C` for line numbers, disabled items, and timestamps.

### Dark Mode Architecture
- **Canvas Base (Dark):** `#141416` (Deep Charcoal).
- **Surface Elevation (Dark):** `#1C1C1F` for problem containers and editor frames.
- **Border Subtle (Dark):** `#2A2A2E`.
- **Ink Primary (Dark):** `#EDEDEC`.
- **Ink Muted (Dark):** `#A0A0A4`.
- **Softened Guinda (Dark Primary):** `#A33B6E` for elevated interactive states, shifting to `#8F2B5B` for secondary accents to avoid chromatic aberration on dark backgrounds.

### Institutional Guinda
- **Guinda IPN:** `#6F1D46`. Used deliberately for:
  - Primary button fills and focused states.
  - Active navigation indicators and chapter progress lines.
  - Inline links and critical textual highlights.
- **Never** deploy Guinda across wide-area card backgrounds, multi-row table rows, or full-screen navigation banners.

### Semantic Judge Verdicts (Online Judge Feedback)
- **Aceptado (AC):** Light: `#0F766E` text on `#F0FDF4` tint with `#BBF7D0` stroke. Dark: `#34D399` text on `#064E3B` surface.
- **Respuesta Incorrecta (WA):** Light: `#BE123C` text on `#FFF1F2` tint with `#FECDD3` stroke. Dark: `#FB7185` text on `#4C0519` surface.
- **Tiempo Límite Excedido (TLE):** Light: `#B45309` text on `#FFFBEB` tint with `#FDE68A` stroke. Dark: `#FBBF24` text on `#451A03` surface.
- **Error de Compilación (CE):** Light: `#C2410C` text on `#FFF7ED` tint with `#FFEDD5` stroke. Dark: `#FB923C` text on `#431407` surface.
- **Evaluando / En Cola:** Light: `#475569` text on `#F8FAFC` tint with a rhythmic Guinda pulse `#6F1D46`. Dark: `#94A3B8` on `#1E293B`.

## Typography

Typographic hierarchy treats code problem sets as academic literature.

### Reading Hygiene & Measure
- **Measure (Line Length):** Problem statements, conceptual explanations, and algorithmic analysis must be bounded to a strict width of 60 to 75 characters (`max-w-prose` or ~680px).
- **Proportional Leading:** Generous line heights (`1.6` to `1.75`) prevent cognitive exhaustion during long multi-paragraph proofs and case definitions.
- **Font Integration:** `Inter` handles human-language instruction with immaculate glyph neutrality. `JetBrains Mono` handles formal syntax, complex math symbols, and compiler outputs without character ambiguity (e.g., distinct 0 vs O, 1 vs l vs I).

### Specialized Usage
- **Inline Code:** Rendered with `JetBrains Mono`, embedded within a soft bone capsule (`#EFECE6` in light mode) with `0.2em 0.4em` padding.
- **Mathematical Formulations:** Constraints such as $1 \le N \le 10^5$ use italicized sans-serif numerals or monospace notation rather than default body styles.

## Layout & Spacing

Layouts follow an asymmetrical two-pane split structure reminiscent of modern educational IDEs and clean reading workspaces.

### The Problem-Solving Workspace
- **Desktop (>= 1024px):** Split-view workspace. Left pane (45–50% width) hosts the editorial problem statement, constraints, and interactive hints within a bounded scrollable pane. Right pane hosts the code editor, I/O runner, and verdict terminal.
- **Tablet (768px - 1023px):** Collapsible split view with quick-tab switching between *Problema* and *Solución*.
- **Mobile (< 768px):** Single-column stacked flow. Problem statements prioritize reading clarity; code blocks scroll horizontally with preserved indentation.

### Spacing Philosophy
Whitespace is deliberate and calm. Components breathe: cards do not crowd one another, and sectional groupings rely on vertical spacing increments (`space-lg` and `space-xl`) rather than heavy colored dividers.

## Elevation & Depth

This design system avoids heavy drop shadows, colored glows, and skeuomorphic embossing. Depth is created through surface contrast and crisp outlines.

### Depth Stratification
1. **Base Tier (Ground):** The warm bone canvas (`#FBFBFA`). Everything sits grounded on this paper-like layer.
2. **First Tier (Cards & Panels):** Pure white `#FFFFFF` panels defined by a crisp 1px hairline border (`#E7E6E2`). No shadow in passive states.
3. **Interactive Hover (Subtle Lift):** On hover, interactive cards gain an imperceptible ambient shadow: `box-shadow: 0 2px 8px -2px rgba(30, 30, 32, 0.04), 0 1px 3px 0 rgba(30, 30, 32, 0.02)`.
4. **Active Focus & Modals:** Modals and floating action drawers sit on a backdrop blur overlay (`backdrop-filter: blur(6px); background: rgba(251, 251, 250, 0.8)`) paired with a razor-thin border `#D8D6CE`.
5. **Code Terminal:** Recessed 1px into the card surface using an inset border rather than a heavy drop shadow.

## Shapes

The geometric tone balances intellectual discipline with friendly accessibility.

- **Base Components (Inputs, Buttons, Badges):** `8px` (`0.5rem`) corner radius. This prevents the harshness of boxy brutalism while avoiding the childish playfulness of pill shapes.
- **Card Containers & Code Playgrounds:** `12px` (`0.75rem`) to frame comprehensive modules.
- **Inline Badges & Verdict Tags:** `6px` radius for tight, structured tag forms.
- **Avatars & Campus Emblems:** Subtle circular geometry or soft square `8px` squircle.

- Padding: `0.25rem 0.625rem`. Border: 1px hairline.
- Icons: Render 14px Lucide glyphs: Check for AC, X for WA, Clock for TLE, Terminal for CE, Loader2 (spin) for Evaluando.

### Cards (Course Modules & Problem Sets)
- Background `#FFFFFF`, border 1px `#E7E6E2`, radius `12px`.
- Padding: `1.5rem`.
- Header: Problem title in `headline-sm` with topic chips aligned right.
- Footer: Subtle metadata row (Dificultad: Principiante / Intermedio / Avanzado; Memoria límite: 128MB; Tiempo: 1.0s) in `body-sm`, text color `#76767C`.

### Code Blocks & Test Case Runners
- Two-column input/output panels: Left column "Entrada de ejemplo", Right column "Salida esperada".
- Background: `#F7F7F5` with `1px solid #E7E6E2`. Top bar featuring language pill (e.g., `C++20`, `Python 3.11`) and a discrete "Copiar" button.
- Font: `JetBrains Mono` at `0.875rem`, line numbers rendered in `#A0A0A4` non-selectable.

### Input Fields & Selects
- Height: `40px`. Background `#FFFFFF`, border 1px `#E7E6E2`, radius `8px`.
- Text `#1E1E20`, placeholder `#76767C`.
- Focus state: Border transitions to `#6F1D46`, outline 1px solid `#6F1D46`. No heavy outer halo.

### Checkboxes & Radios
- Box size: `18px x 18px`. Radius: `4px` (checkbox), full circle (radio).
- Unchecked: Border 1.5px `#C4C3BE`, background `#FFFFFF`.
- Checked: Fill `#6F1D46` with crisp white checkmark vector.

### Academic Topic Chips
- Small metadata tags (`Estructuras de Datos`, `Grafos`, `Recursión`).
- Background: `#F3F2EE`, text `#4A4A4F`, border none, radius `6px`, padding `0.2rem 0.5rem`, font size `0.75rem`.
