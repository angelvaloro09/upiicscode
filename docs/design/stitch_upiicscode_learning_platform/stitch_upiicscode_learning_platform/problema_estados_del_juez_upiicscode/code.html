Inversión de Lista Enlazada

Dada la cabecera (head) de una lista simplemente enlazada, invierta los punteros de los nodos de tal manera que el último nodo sea la nueva cabecera y el primer nodo apunte a puntero nulo.

Firma de Función
ListNode* reverseList(ListNode* head);
Definición de Nodo
struct ListNode {
int val;
ListNode *next;
ListNode(int x) : val(x), next(nullptr) {}
};
Restricciones de Complejidad
  • El número de nodos en la lista está en el rango [0, 5000].
  • El valor de cada nodo satisface -5000 ≤ Node.val ≤ 5000.
  • Complejidad temporal requerida: O(n) en tiempo estricto.
  • Complejidad espacial requerida: O(1) memoria auxiliar (inversión in-place).
