Lección 3.1: Apuntadores y Manejo de Memoria en C

Una comprensión minuciosa de la arquitectura de ejecución y el ciclo de vida del stack y heap es el pilar indispensable para dominar árboles dinámicos, grafos y estructuras autorreferenciadas sin fugas de memoria.

1. El Modelo de Espacio Lineal y Punteros

A nivel de hardware y sistema operativo con direccionamiento virtual de 64 bits, la memoria RAM es visualizada por el proceso como una gigantesca secuencia contigua de bytes direccionables secuencialmente de 0x0000000000000000 a 0x7FFFFFFFFFFFFFFF en espacio de usuario.

Un apuntador no es una construcción mágica: es sencillamente una variable escalar cuyo valor almacenado representa la dirección hexadecimal del primer byte de otro objeto situado en dicho espacio lineal.

3. Desreferenciación y Aritmética de Punteros

El operador & extrae la dirección de memoria física virtual de un l-value, mientras que el operador unario * accede al contenido de la celda de destino. Cuando se realiza aritmética como ptr + 1, el compilador multiplica el incremento por sizeof(*ptr) en bytes, garantizando alineamiento estricto.

typedef struct Nodo {
    int valor;
    struct Nodo* siguiente;
} Nodo_t;

int main(void) {
    // Reserva dinámica en el segmento Heap
    Nodo_t* ptr_nodo = (Nodo_t*)malloc(sizeof(Nodo_t));
    
    if (ptr_nodo == NULL) {
        perror("Fallo crítico de asignación virtual");
        return 1;
    }

    ptr_nodo->valor = 42;
    ptr_nodo->siguiente = NULL;

    printf("Dirección asignada: %p | Valor: %d\n", (void*)ptr_nodo, ptr_nodo->valor);

    // Liberación obligatoria para evitar fuga de memoria
    free(ptr_nodo);
    ptr_nodo = NULL; // Prevención de puntero colgante (Dangling pointer)

    return 0;
}

4. Violaciones de Segmentación (SIGSEGV) y Buenas Prácticas

Una señal SIGSEGV ocurre cuando la Unidad de Manejo de Memoria (MMU) detecta una falta de página irresoluble: el proceso intenta leer o escribir en una dirección virtual que o bien no tiene una tabla de páginas física mapeada, o bien viola los permisos de solo lectura del descriptor de segmento.

warning Advertencia de Arquitectura · Errores Fatales Comunes
  • Desreferencia de Puntero Nulo (NULL): Acceder a *ptr cuando ptr == 0x0 invoca comportamiento indefinido inmediato al chocar con la página de guarda del kernel.
  • Dangling Pointers (Punteros Huérfanos): Leer una estructura tras ejecutar free() conduce a lectura de basura o corrupciones silenciosas del allocator.
  • Heap Overflow: Escribir más allá del bloque reservado corrompe las cabeceras de fragmentos contiguos de ptmalloc.
