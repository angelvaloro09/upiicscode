flag Objetivos de Aprendizaje

  • Construir una plantilla de clase (Template C++) con nodos bidireccionales (prev y next).
  • Garantizar complejidad temporal en tiempo constante O(1) para inserciones y eliminaciones en ambos extremos (push_front, push_back, pop_front, pop_back).
  • Manejo estricto de memoria heap mediante operadores new y delete, evitando fugas de memoria (zero memory leaks).

memory Restricciones y Criterios de Evaluación

1. Prohibido STL: No está permitido incluir cabeceras de contenedores estándar como <list>, <vector> o <deque>. La implementación de los nodos debe ser nativa.

2. Destructor & RAII: El destructor ~DoubleLinkedList() debe recorrer y liberar cada nodo asignado individualmente. Las pruebas automatizadas del servidor ejecutarán Valgrind --leak-check=full. Cualquier byte huérfano descontará el 30% del puntaje.

3. Excepciones: Invocar métodos de extracción o lectura sobre una lista vacía debe lanzar una excepción estándar std::underflow_error.
