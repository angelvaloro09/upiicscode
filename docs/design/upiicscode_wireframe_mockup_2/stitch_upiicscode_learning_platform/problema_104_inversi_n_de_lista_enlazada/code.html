Inversión de Lista Enlazada

Manejo de punteros dinámicos y recorrido en tiempo lineal.

Descripción del problema

Dado el puntero inicial head de una lista simplemente enlazada, invierte el orden de los elementos y devuelve la nueva cabeza de la lista.

Debes realizar la inversión reasignando los punteros next en un solo pase. No está permitido duplicar los nodos ni modificar únicamente sus valores internos.

Esquema en memoria Estado inicial vs. invertido

Casos de Ejemplo

Ejemplo 1
Entrada (STDIN) 
head = [1, 2, 3, 4, 5]
Salida Esperada (STDOUT) 
[5, 4, 3, 2, 1]
Ejemplo 2 (Lista Pequeña)
Entrada (STDIN) 
head = [1, 2]
Salida Esperada (STDOUT) 
[2, 1]

Restricciones Académicas

  • El número de nodos en la lista se encuentra en el rango 1 ≤ n ≤ 10^5.
  • El valor de cada nodo satisface -5000 ≤ Node.val ≤ 5000.
  • Complejidad temporal requerida: O(n) en un único pase lineal.
  • Complejidad espacial auxiliar: O(1) de memoria adicional.

// Estructura del nodo de lista simple: struct Node { int val; Node* next; Node() : val(0), next(nullptr) {} Node(int x) : val(x), next(nullptr) {} Node(int x, Node* n) : val(x), next(n) {} }; class Solution { public: Node* invertList(Node* head) { Node* prev = nullptr; Node* curr = head; Node* nextNode = nullptr; while (curr != nullptr) { nextNode = curr->next; // Guardar enlace curr->next = prev; // Invertir puntero prev = curr; // Avanzar previo curr = nextNode; // Avanzar actual } return prev; // Nueva cabeza de la lista invertida } };
