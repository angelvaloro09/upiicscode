Lección 3.1: Apuntadores y Manejo de Memoria en C

Cátedra de Algoritmia • Lectura técnica y conceptual

Bienvenido a uno de los temas más representativos del lenguaje C y de la computación clásica. Comprender los apuntadores no es solo aprobar la asignatura; es adquirir una visión nítida de cómo interactúa el procesador con la memoria física de tu máquina.

Diagrama 3.1 • Modelo secuencial de celdas de memoria Arquitectura x86-64

Representación conceptual de la memoria RAM secuencial: el apuntador ptrMatricula contiene como valor la dirección de memoria hexadecimal donde se aloja la variable matricula.

1. ¿Qué es un apuntador?

Imagina la memoria RAM como una extensa fila de casilleros numerados en el pasillo del edificio de laboratorios de UPIICSA. Cada casillero tiene un número único (su dirección) y adentro puede albergar un contenido puntual: un entero, un carácter o un valor flotante.

bookmark Definición Fundamental

Un apuntador es una variable especializada cuyo propósito único no es almacenar un valor computacional directo (como una edad o un promedio), sino la dirección de memoria hexadecimal donde reside otra variable.

2. Declaración y operador de dirección (&)

Para obtener la ubicación de una variable en memoria utilizamos el operador ampersand (&), comúnmente llamado operador de dirección.

C99 • Operador & 
1int matricula = 20216008;
2int *ptrMatricula = &matricula; // ptrMatricula almacena la dirección de matricula

3. Desreferenciación (*)

Una vez que tienes el apuntador orientado a un casillero, ¿cómo modificas su contenido? Usando el asterisco (*). Este proceso se llama desreferenciación o indirección: estás navegando por el puntero para manipular el dato real.

lightbulb Ejemplo Práctico: Modificación por Referencia

Si ejecutas *ptrMatricula = 20250001;, la variable original matricula cambiará inmediatamente su valor, sin necesidad de invocarla por su identificador directo.

4. Asignación dinámica: malloc y free

Hasta aquí, las variables residían en la pila (Stack). Sin embargo, cuando no conocemos el tamaño del arreglo antes de compilar o requerimos que los datos perduren más allá del ciclo de vida de la función, solicitamos memoria directamente al sistema operativo en el montículo (Heap).

memoria_dinamica.c 
 1#include <stdio.h>
 2#include <stdlib.h>
 3
 4int main() {
 5    int *ptr = (int*) malloc(sizeof(int) * 5);
 6    if (ptr == NULL) {
 7        fprintf(stderr, "Error al asignar memoria\n");
 8        return 1;
 9    }
10    for (int i = 0; i < 5; i++) {
11        ptr[i] = (i + 1) * 10;
12        printf("ptr[%d] = %d en %p\n", i, ptr[i], (void*)&ptr[i]);
13    }
14    free(ptr);
15    return 0;
16}
warning Advertencia de Arquitectura

Siempre verifica que el resultado de malloc() sea distinto de NULL antes de acceder a la memoria. En sistemas con recursos limitados o ante solicitudes excesivas, la asignación fallará y desreferenciar un puntero nulo provocará un Segmentation Fault inmediato.

5. Errores comunes

En C no contamos con un recolector de basura automatizado como en Java o Python. Cada byte que solicitas con malloc o calloc debe ser explícitamente devuelto con free.

Dangling Pointer

Ocurre cuando liberas la memoria pero continúas utilizando el apuntador sin antes igualarlo a NULL.

Fuga de Memoria (Memory Leak)

Si reasignas el apuntador sin antes haber ejecutado free(), esos bytes quedarán inaccesibles e irrecuperables hasta finalizar el proceso.
