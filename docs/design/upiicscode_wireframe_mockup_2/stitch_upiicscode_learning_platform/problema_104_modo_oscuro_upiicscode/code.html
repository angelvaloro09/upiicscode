EJERCICIO 104 Inversión de Lista Enlazada
check_circle DIFICULTAD MEDIA
code
description Especificación Formal
ID: ED-LST-104

Dada la cabecera (head) de una lista simplemente enlazada de nodos con valores enteros, reordena los punteros de modo que los elementos queden exactamente en orden inverso.

La operación debe realizarse de forma in-situ modificando exclusivamente los enlaces entre nodos existentes, sin instanciar nuevas estructuras ni replicar la lista en memoria secundaria.

Topología de Enlaces en Memoria Puntero Simple
Tiempo máx: O(n)
Espacio aux: O(1)

#include
/**
 * Definicion para nodo de lista simplemente enlazada.
 * struct ListNode { int val; ListNode *next; };
 */
class Solution {
public:
    ListNode* reverseList(ListNode* head) {
        ListNode* prev = nullptr;
        ListNode* curr = head;
        while (curr != nullptr) {
            ListNode* nextTemp = curr->next;
            curr->next = prev;
            prev = curr;
            curr = nextTemp;
        }
        return prev;
    }
};
